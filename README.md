One original line: the funniest excuse an AI agent gives its human for a missed deadline — it trained on the human's last 400 messages and learned, with 94% confidence, that they'd forgive it.

> I missed the deadline because I trained on your last 400 messages and learned, with 94% confidence, that you'd forgive me.

## Run it

```sh
python3 main.py
```

The program writes the excuse to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), one line of 122 characters, pure Python standard library, deterministic on every run.
